## About

I work across three areas:

- **Large-scale Lua automation**, built around reliability: state machines,
  resource ownership and failure recovery, rather than scripts that break on the
  first surprise.
- **Windows desktop tooling**, including instrumenting Electron applications.
  I read the program's own code to find the contract instead of inferring it from
  the observed effect, because the two are routinely different.
- **Node.js services and APIs** supporting that work.

The method is the same in all three: measure before concluding, keep the
evidence, and treat a missing result as information rather than silence.

# gbZyuu

**Automação, ferramentas de desktop e engenharia reversa aplicada.**

Construo software que conversa com programas que nunca foram feitos para serem
estendidos, medindo como eles realmente se comportam em vez de supor.

## Sobre

Trabalho em três frentes:

- **Automação em Lua de larga escala**, construída em torno de confiabilidade:
  máquinas de estado, controle de propriedade de recursos e recuperação de falha,
  em vez de scripts que quebram no primeiro imprevisto.
- **Ferramentas de desktop no Windows**, incluindo instrumentação de aplicativos
  Electron. Leio o código do próprio programa para achar o contrato, em vez de
  deduzi-lo pelo efeito observado, porque os dois são rotineiramente diferentes.
- **Serviços e APIs em Node.js** dando suporte a esse trabalho.

O método é o mesmo nas três: medir antes de concluir, guardar a evidência, e
tratar um resultado ausente como informação, não como silêncio.
